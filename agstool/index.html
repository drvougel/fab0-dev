agstool

Kommandozeilen-Werkzeug (C++) für Adventure Game Studio 3.6.1. Es legt Räume (.crm) aus einer JSON-Beschreibung an und ersetzt Sprites (acsprset.spr), ohne dass der Editor offen sein muss. So lassen sich Räume per Skript oder mit KI-Hilfe bauen.

Was es kann

  • room-build: Raum aus Vorlage + JSON: Hintergrund, Laufflächen, Hotspots mit Namen, Lauf-Zielpunkt und Ereignissen, Regionen, Walk-behinds, Ränder
  • room-register: Raum in Game.agf eintragen
  • sprite-set, sprite-sync-agf: Sprites aus PNG ersetzen und Grössen abgleichen
  • info: Räume und Sprites prüfen, Masken als PNG exportieren

Es nutzt die offizielle AGS-Common-Bibliothek (ReadRoomData/WriteRoomData, SpriteFile) und schreibt kein eigenes Dateiformat. Die Räume werden vom Editor 3.6.1.35 kompiliert und laufen auch in ScummVM. Entstanden für freehab.

Beispiel

{
  "background": "art/pal/rampe_nacht.png",
  "walkable": "art/rooms/rampe_nacht.walk.png",
  "hotspots": {
    "png": "art/rooms/rampe_nacht.hot.png",
    "list": [{ "index": 1, "name": "Pilatus", "script": "hPilatus",
               "walkTo": [150, 175], "events": ["AnyClick"] }]
  },
  "roomEvents": ["FirstLoad", "Load"]
}
